Appendix

How to Set Up ReactionSys and Stream So Later Tabs Work Correctly

This appendix focuses on the chemistry and inlet-state objects reused across Prediction Models, Tanks-in-Series, Dispersion Model, and Tab 5. A large fraction of downstream issues come from object definitions that are syntactically valid but conceptually inconsistent.

ReactionSys First Principles

Element What to define carefully
Species listUse a stable order and keep it consistent with all later indexing.
Stoichiometric matrixConfirm signs and coefficients match the intended reaction scheme.
KineticsUse rate expressions consistent with the same species ordering and units convention.
Component namesPrefer explicit names; otherwise the app falls back to CA, CB, CC, and so on.

How Species Order Propagates

The app uses species order repeatedly: stoichiometry, inlet concentrations, outlet tables, conversion selectors, and custom kinetics all depend on the same indexing logic.

  • If species 1 is the reactant in the kinetic law, it must still be species 1 in the stream composition.
  • If you later relabel components manually, verify that the actual order did not change underneath the labels.
  • Conversion is only meaningful for functional reactants, not automatically for every species shown in a table.

Writing Custom Kinetics Safely

  1. Use the expected concentration indexing convention consistently.
  2. Keep the rate law physically compatible with the stoichiometric definition.
  3. Check units before comparing two models numerically.
  4. Remember that some model routes impose extra assumptions, especially Dispersion Model with open-open.
Common mistake: a rate expression can look mathematically plausible and still be wrong if it refers to the wrong concentration index or assumes a different stoichiometric sign convention than the one used by the app.

Setting Up the Stream

Part of the stream Why it matters later
Volumetric flowNeeded to connect residence time, volume, and inlet-state interpretation.
Molar flows or inlet concentrationsDefine the composition used to build the reactive inlet vector.
Species alignmentMust match the ReactionSys species ordering.
UnitsDetermine how values are entered and displayed before internal SI conversion.

In the current Tab 5 Optimization workflow, inlet concentrations are the active manipulated variables, and their visible units are inherited from the loaded stream.

Recommended Setup Workflow

  1. Define the species list and stoichiometry first.
  2. Enter or verify the kinetic law second.
  3. Load or define the feed stream with the same species order.
  4. Check that the names shown in selectors and tables match the intended chemistry.
  5. Run a first comparison in Prediction Models before moving to specialized tabs.

Typical Setup Problems

Problem What to verify
Conversion is missing for the species you expectedWhether that species is actually a functional reactant for the loaded chemistry and inlet state.
Outlet values look physically impossibleSpecies ordering, concentration units, and whether the stream matches the reaction definition.
Dispersion open-open warns about unsupported kineticsWhether the current rate law is truly compatible with the open-open exact route.
Optimization bounds feel inconsistentRemember that the table shows inherited input units while the solver works internally in SI.
